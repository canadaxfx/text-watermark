# 文本水印工具 / Text Watermark Tool

**原创内容保护工具，专为中文社交媒体设计。**

🌐 **在线使用（无需下载）**：https://canadaxfx.github.io/text-watermark/

---

## 下载本地版

1. 点击本页面的 **`watermark.html`**
2. 点击右上角 **Download raw file**（下载图标）
3. 保存到本地，用浏览器打开即可（Chrome / Safari / Edge）

> 无需安装，无需联网，所有数据在本地处理，不上传任何内容。

---

## 功能

| 标签页 | 功能 |
|--------|------|
| 文字转水印图片 | 将文字渲染为图片，叠加斜向水印，防止直接复制搬运 |
| 纯文字水印 | 插入括号标识 + 不可见零宽字符，三层保护，支持存证图片 |
| 验证标识 | 检测可疑文字是否含有本工具生成的水印 |

---

## 使用方法

1. **发图片**：进入"文字转水印图片"，粘贴文章，生成下载
2. **发文字**：进入"纯文字水印"，粘贴原文，填写你的名字/代号，复制带水印文本发布
3. **留存证**：生成水印后点"生成存证图片"，保存到本地备查
4. **验证**：进入"验证标识"，粘贴可疑文字，一键检测
